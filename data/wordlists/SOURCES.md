# Bundled wordlists — provenance

Every file shipped under `data/wordlists/` is listed here with where it came
from and under which licence, as far as that can be established from the file
itself, the installer history (`git log -S<name> -- install.sh`) or well-known
provenance. **No licence below is inferred**: where none is recorded the entry
says so, and the maintainer should confirm it before the v5.0.0 release.

v2 reads these through the `[paths]` table (`fuzz_wordlist`, `lfi_wordlist`,
`ssti_wordlist`, `subs_wordlist`, `headers_inject`, `wordlists_dir`); v1 reads
the same files through the matching `reconftw.cfg` variables.
