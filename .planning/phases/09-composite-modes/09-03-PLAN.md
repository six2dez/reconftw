<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| v1 alias args → cobra arg slice | translateV1Args must not execute user-supplied arg values; pure string substitution only |
| --list FILE path → filesystem | Path must be validated as a readable file before opening; no path traversal |
| dry-run output → user terminal | Tool arg strings may contain registered secrets (D-10) |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-09-03-01 | Tampering | translateV1Args command injection | mitigate | translateV1Args performs pure string substitution — no shell eval, no exec.Command, no string interpolation; translated values are only subcommand names from a hardcoded allowlist (v1SubcommandFlags map) and flag name rewrites ("-d"→"--target") |
| T-09-03-02 | Tampering | --list FILE path traversal | mitigate | readTargetList validates path existence and readability before opening; each target line from the file is passed through validate_domain equivalent before being used as a workspace target |
| T-09-03-03 | Information Disclosure | --dry-run output on piped/non-TTY paths | mitigate | D-10 resolved in Plan 09-02 composite dry-run printers; main.go bootstrap logger is already a RedactingHandler (documented with comment in this plan); no new raw Fprintf paths added here |
| T-09-03-04 | Denial of Service | --list file with 10,000 targets | accept | Sequential processing means linear time; no bounded limit imposed (operator's responsibility); slog.Warn per failure provides observability |
| T-09-03-05 | Spoofing | deprecated flag double-subcommand injection | mitigate | translateV1Args Pitfall-4 guard: if args[0] is already a known subcommand, skip mode-flag injection; prevents double-insertion attack |
| T-09-03-SC | Tampering | npm/pip/cargo installs | accept | No new external dependencies; pure Go stdlib |
</threat_model>
