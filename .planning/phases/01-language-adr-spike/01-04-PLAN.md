|--------|-------|-------|-------|------|-------|------|-------------------------------|
| Go     | <n>   | <n>   | <n>   | <n>  | <n>   | <n>% | <yes|no>                       |

Shell snippet to compute (paste output into table above):
```bash
for lang in go python; do
    awk -v lang="$lang" '$1==lang {sum+=$3; sumsq+=$3*$3; n++} END {
        if (n>0) {
            mean = sum/n
            stdev = sqrt((sumsq - n*mean*mean) / (n>1 ? n-1 : 1))
            cov = (mean > 0 ? 100*stdev/mean : 0)
            printf "%s mean=%.0f stdev=%.0f cov=%.1f%%\n", lang, mean, stdev, cov
        }
    }' spike/.rss_measurements.log
done
```
