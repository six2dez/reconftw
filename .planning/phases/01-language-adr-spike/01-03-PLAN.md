1. **`spike/python/src/spike/proc.py`** — asyncio subprocess wrapper. Exact API:
   ```python
   from typing import Awaitable, Callable
   import asyncio, os, signal

   async def run(
       name: str,
       args: list[str],
       line_fn: Callable[[bytes], None] | None = None,
       timeout: float | None = None,
   ) -> int:
       """Run name+args under process-group isolation (start_new_session=True).
       On cancellation/timeout, sends SIGTERM to the entire process group via
       os.killpg, waits 5 seconds grace, then SIGKILL escalation.

       stdout is streamed line-by-line through line_fn; None means stdout is discarded.

       Returns process exit code.

       Source: .planning/phases/01-language-adr-spike/01-RESEARCH.md §Pattern 1
       Pitfall: .planning/research/PITFALLS.md §1.2 (kill-tree, top-impact)
       """
   ```

   Implementation MUST follow RESEARCH.md §Pattern 1 verbatim:
   - `proc = await asyncio.create_subprocess_exec(name, *args, stdout=asyncio.subprocess.PIPE, stderr=asyncio.subprocess.PIPE, preexec_fn=os.setsid)` — `preexec_fn=os.setsid` makes the child the process-group leader (POSIX-only; the spike runs on macOS arm64 and Linux per RESEARCH.md §Environment Availability)
   - If `line_fn`: `async for line in proc.stdout: line_fn(line.rstrip(b"\n"))`
   - On cancellation (try/except `asyncio.CancelledError`) OR `asyncio.TimeoutError`:
     ```python
     os.killpg(proc.pid, signal.SIGTERM)
     try:
         await asyncio.wait_for(proc.wait(), timeout=5.0)
     except asyncio.TimeoutError:
         if proc.returncode is None:
             os.killpg(proc.pid, signal.SIGKILL)
             await proc.wait()
     raise
     ```
   - On normal completion: `return await proc.wait()`

2. **`spike/python/src/spike/output.py`** — atomic_write_jsonl. Exact API:
   ```python
   import os, json, tempfile

   def atomic_write_jsonl(target: str, lines: list[dict]) -> None:
       """Write lines (each a dict) to target atomically as JSONL.
       4-step pattern: tempfile (same dir as target) + fsync + os.replace + parent-dir fsync.
       Parent-dir fsync is the often-forgotten step (most implementations stop at 3).

       Source: .planning/phases/01-language-adr-spike/01-RESEARCH.md §Pattern 2
       Pitfall: .planning/research/PITFALLS.md §3.1 (atomic write, top-5)
       """
   ```

   Implementation MUST follow RESEARCH.md §Pattern 2 verbatim:
   - `d = os.path.dirname(target) or "."`
   - `fd, tmp = tempfile.mkstemp(prefix=os.path.basename(target) + ".tmp.", dir=d, text=False)`
   - try:
     - `with os.fdopen(fd, "wb") as f: for line in lines: f.write(json.dumps(line).encode() + b"\n"); f.flush(); os.fsync(f.fileno())`
     - `os.replace(tmp, target)` (atomic rename)
     - **CRITICAL**: `parent_fd = os.open(d, os.O_DIRECTORY); try: os.fsync(parent_fd); finally: os.close(parent_fd)`
   - except: `os.unlink(tmp); raise`
