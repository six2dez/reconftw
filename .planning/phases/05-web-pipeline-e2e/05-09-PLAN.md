<objective>
TDD RED→GREEN: write the multi-writer integration test (Task 1, which fails against pre-fix
code), then apply the staging contract to ALL multi-writer web artefacts so the test goes GREEN
(Tasks 2–3). This fold keeps the default `go test ./...` gate GREEN at every wave boundary.

The staging contract: tasks writing urls/findings/waf STOP calling app.Tree.Append directly.
Each writes a unique per-task staging file at inputs/&lt;artefact&gt;.&lt;tool&gt;.jsonl. The existing
MergeStage / MergeAllWebArtefacts in merge.go (which already globs inputs/&lt;artefact&gt;.*.jsonl)
becomes the SINGLE app.Tree.Append caller per artefact after each stage — EXCEPT for urls
where urldedup IS the single semantic-dedup writer.

URL PIPELINE DESIGN (WEB-14 compliant, single-writer):
  1. urls-fetch stage: katana/urlfinder/waymore write inputs/urls.{katana,urlfinder,waymore}.jsonl
  2. Pre-js-extract intermediate: MergeStage("urls") populates artefacts/urls.jsonl from the
     fetch-stage staging files — js-extract/js-analyze tasks read their JS URL input from this file
  3. js-extract + js-analyze stages: subjs/jsluice/jsa/mantra write inputs/urls.{subjs,jsluice,jsa,mantra}.jsonl staging files (do NOT call Tree.Append)
  4. urls-dedup (FINAL, after js-analyze): urldedup globs ALL inputs/urls.*.jsonl (fetch + js sources),
     runs urless/p1radup semantic dedup over the FULL union, then calls app.Tree.Append("urls") ONCE.
     This Tree.Append REPLACES the intermediate artefacts/urls.jsonl with the final deduped set.

This design ensures:
  - Exactly ONE semantic-dedup Append writer for urls (urldedup, step 4)
  - The intermediate MergeStage("urls") in step 2 is a raw-byte merge for js-task input only;
    urldedup's Tree.Append overwrites it with the final semantic-dedup result
  - js tasks read from artefacts/urls.jsonl (populated by step 2) — no stale reads
  - WEB-14: final urls.jsonl is urless/p1radup-deduped over ALL URL sources

urldedup in THIS PLAN is rewritten to glob inputs/urls.*.jsonl (not read artefacts/urls.jsonl)
and to use app.Tree.Append("urls") not os.WriteFile. The stage ordering that places urldedup
AFTER js-analyze is set in 05-10.

Mirror: internal/modules/subdomains/passive.go + doc.go = canonical reference.
