<objective>
Fix the DependsOn violations caused by intra-stage ordering (CR-04). Wave 2 — blocked on 05-09
(staging contract must be in place before stage split, since urldedup now reads inputs/urls.*.jsonl
that only populate after all URL-producing stages complete).

RunStage fires every task in a slice CONCURRENTLY and does NOT enforce DependsOn ordering;
ordering comes from SEQUENTIAL stage calls. The current stage layout puts mutually-dependent
tasks in the same concurrent stage.

URL PIPELINE DESIGN (WEB-14 single-writer):
  urldedup is the FINAL stage (after js-analyze). It globs ALL inputs/urls.*.jsonl staging files
  (from katana/urlfinder/waymore AND subjs/jsluice/jsa/mantra) and calls Tree.Append("urls") once
  with urless/p1radup semantic dedup applied over the full union. No MergeStage("urls") after
  js-analyze — urldedup IS the merge step.

  BUT js-extract/js-analyze tasks read their JS URL input from artefacts/urls.jsonl. To give
  them that file WITHOUT urldedup running yet, we call an intermediate MergeStage("urls") AFTER
  urls-fetch and BEFORE js-extract. This intermediate merge populates artefacts/urls.jsonl with
  the raw-byte-deduped katana/urlfinder/waymore set. When urldedup runs last, its Tree.Append
  REPLACES artefacts/urls.jsonl with the final semantically-deduped full union. Tree.Append uses
  REPLACE semantics so this is correct.

Split the existing 4 stages into 9 stages that honor all declared DependsOn edges:

  probe           → [web.httpx]
  analysis-waf    → [web.wafw00f, web.cdncheck]           (must complete before nuclei reads waf.jsonl)
  analysis        → [web.nuclei, web.screenshot, web.ffuf, web.favirecon, web.vhostfinder,
                     web.hakoriginfinder, web.csprecon]     (nuclei DependsOn wafw00f ✓)
  urls-fetch      → [web.katana, web.urlfinder, web.waymore]
  [intermediate]  → MergeStage("urls") — populates artefacts/urls.jsonl for js tasks; NOT a stage
  js-extract      → [web.subjs, web.sourcemapper]          (reads artefacts/urls.jsonl ✓)
  js-analyze      → [web.jsluice, web.jsa, web.mantra]     (jsluice DependsOn subjs/sourcemapper ✓;
                                                             jsa/mantra DependsOn subjs ✓)
  bypass          → [web.nomore403, web.shortscan, web.gxss, web.arjun]
  urls-dedup      → [web.urldedup]                         (LAST: globs ALL inputs/urls.*.jsonl ✓)

Wire MergeStage calls after each stage that has multi-writer participants:
  - After analysis-waf:  MergeStage(ctx, app, "waf")     — merges wafw00f+cdncheck staging
  - After analysis:      MergeStage(ctx, app, "findings") — merges nuclei staging
  - After urls-fetch:    MergeStage(ctx, app, "urls")     — INTERMEDIATE: populates artefacts/urls.jsonl
                                                             for js-extract tasks to read
  - After js-analyze:    NO MergeStage("urls") — urldedup (urls-dedup stage) IS the merge
  - After bypass:        MergeStage(ctx, app, "findings") — merges nomore403/shortscan/gxss/arjun

NOTE: stub_subcommands.go also has a printWebDryRun function with the same stage list — update
BOTH the live-run stages slice and the dry-run stages slice to stay consistent.

Purpose: Ensure declared DependsOn ordering is actually honored in execution; ensure urldedup
runs after all URL producers for WEB-14 single-writer compliance.
Output: Modified cmd/reconftw/stub_subcommands.go (stage definitions + merge calls).
