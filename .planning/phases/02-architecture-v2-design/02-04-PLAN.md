<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Task.Run() return value → Scheduler | Task errors classified against 7-class hierarchy; determines retry/skip/abort behavior |
| OutOfScope error → OutputTree | Scope filter enforcement — OutOfScope prevents out-of-scope data from being written |
| AxiomFailure → FailoverBackend | Triggers local retry without losing work; must not loop infinitely |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-04-01 | Elevation of Privilege | Scope filter bypass via Task.Run() returning without scope check | mitigate | ADR specifies scope filter at OutputTree.Append boundary, not Task boundary; OutOfScope error class returned at write time, not opt-in by task authors |
| T-02-04-02 | Information Disclosure | ConfigError.Message including raw secret value | mitigate | ADR explicitly states: "ConfigError.Message MUST NOT include raw secret values" (Pitfall 2 note in §6) |
| T-02-04-03 | Denial of Service | Circular DependsOn in Task Registry causing scheduler deadlock | mitigate | ADR specifies Registry.Build() must run topological sort cycle detection at startup (Pitfall 3 note in §6); cycles are ConfigError, not runtime error |
| T-02-04-04 | Denial of Service | Unclosed Backend.Stream() channel causing goroutine leak | mitigate | ADR Backend.Stream() godoc specifies "Caller MUST drain the channel until closed" (Pitfall 4 mitigation) |
| T-02-04-05 | Information Disclosure | AxiomFailure.Inner containing credentials in error chain | mitigate | ADR specifies Inner error must not include raw credential values; use Redactor.Redact() on error strings before logging |
  T-02-04-SC | Tampering | npm/pip/cargo installs | accept | Plan 04 installs no packages |
</threat_model>
