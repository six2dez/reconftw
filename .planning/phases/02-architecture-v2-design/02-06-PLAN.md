    ### Glossary (alphabetical, one-line definitions):
    Define every term used in interface signatures and section headings:
    - **AppContext** — dependency kernel struct passed by pointer to every Task.Run(); wired once at startup
    - **AtomicWriter** — write pattern: tempfile + fsync + rename + parent-fsync; only allowed write path for artefact files
    - **AxiomFailure** — error class for Axiom infrastructure failure (SSH timeout, fleet unreachable); triggers failover to LocalBackend
    - **Backend** — interface abstracting local vs distributed (Axiom) subprocess execution
    - **ChecksumMismatch** — error class returned by installer when SHA-256 hash verification fails
    - **CompatWriter** — writes bash-shape files to _compat/ as LifecycleAware.OnEnd() hook; maintains Recon/<domain>/ symlink farm
    - **ConfigError** — error class for config load/validation failures; carries file:line:key context; Message MUST NOT contain raw secret values
    - **failure_policy** — "best_effort" or "fail_fast" configured per module group; fail_fast cancels peers on first error
    - **OutOfScope** — error returned by OutputTree.Append when a finding fails scope check; prevents out-of-scope data from being written
    - **Result** — outcome struct returned by Task.Run(): Status + Duration + Outputs (paths written) + Stats
    - **ScopeError** — error class for domain/IP input validation failures (distinct from OutOfScope which is about finding scope)
    - **Secret** — string type with LogValue() returning "***"; used for all credential fields in config structs
    - **Scheduler** — bounded concurrency engine; wraps errgroup.SetLimit(N) + failure_policy dispatch
    - **Status** — task terminal state: done | errored | cancelled | skipped
    - **Task** — smallest schedulable unit of recon work; self-registers via init(); declares DependsOn for DAG ordering
    - **ToolError** — error class for non-zero tool exit codes; carries tool name, exit code, stderr excerpt
    - **ToolTimeout** — error class for per-task context deadline exceeded; carries tool name and configured timeout
