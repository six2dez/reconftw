| Config secrets → slog output | Two-layer defense (type + sink) must both be present; neither alone is sufficient |
| v1 deprecated flags → v2 behavior | Deprecated flags must warn but remain functional; removal at v2.2.0 only |
| Test Ring 2 (MockBackend) → real filesystem | Integration tests use in-memory mocks; no real tool execution in CI unit/integration rings |

| T-02-05-02 | Information Disclosure | Secret.String() exposure via fmt.Sprintf | mitigate | ADR BINDING note: "do not add Secret.String()"; golangci-lint rule Phase 3 adds for *Key/*Token/*Password/*Secret fields not typed as log.Secret |
