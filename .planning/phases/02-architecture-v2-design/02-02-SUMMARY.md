## Decisions Made

- Used koanf/v2 as mandated config library (never viper — key lowercasing breaks legacy alias table)
- Used TOML literal strings (single-quoted) for the SSRF regex value containing `\\.` sequences — prevents TOML parse errors from invalid escape sequences in basic strings
- Merged Task 1 and Task 2 into a single commit since both tasks modified the same file and were verified together
- Dropped backtick formatting from the Validation Tag column in §2.5 table so grep `'| min='` pattern works for verification
