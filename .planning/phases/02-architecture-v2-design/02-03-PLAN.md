<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| artefacts/ JSONL writer → filesystem | AtomicWriter prevents torn writes; scope filter at OutputTree.Append prevents out-of-scope data |
| _compat/ symlink layer → user scripts | Symlinks provide v1 path compatibility; atomic creation prevents broken symlink state |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-02-03-01 | Tampering | AtomicWriter (tempfile+fsync+rename pattern) | mitigate | ADR locks 4-step pattern with Step 4 (parent dir fsync) as mandatory; spec cites spike/go/internal/output/atomic.go as canonical |
| T-02-03-02 | Elevation of Privilege | OutOfScope data written to artefacts/ | mitigate | ADR specifies scope filter at OutputTree.Append boundary — Task code cannot bypass it; OutOfScope error class returned instead |
| T-02-03-03 | Tampering | Compat symlink pointing outside workspaces/ | mitigate | AtomicSymlink uses temp path in same dir as link (same filesystem); no ability to point outside workspace via API |
| T-02-03-04 | Information Disclosure | config.snapshot.toml in inputs/ (API keys visible) | mitigate | Config snapshot written with Secret fields redacted (same Secret type + Redactor used for logging); raw API key values never written to disk in snapshot |
| T-02-03-SC | Tampering | npm/pip/cargo installs | accept | Plan 03 installs no packages |
</threat_model>
