<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Task.Run → app.Tools.Run | Tool name + args derived from config (domain string, token file path) cross into subprocess dispatch |
| Task.Run → staging file write | Tool stdout (raw hostnames) written to workspace inputs/ before scope filtering |
| MergeStage → app.Tree.Append | Merged/deduped hostnames enter scope-filter boundary before disk write |
| GitHub/GitLab token → log/notifier | Bearer tokens in tool invocation must never appear in log lines |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-01-01 | Injection | SubfinderTask.Run args (domain string) | mitigate | Domain comes from app.Target.Domain validated by NewTarget regex `^[a-zA-Z0-9.-]+$` before AppContext built; Go slice args never shell-expanded |
| T-04-01-02 | Information Disclosure | GitHub/GitLab token in log stderr | mitigate | Read token file content, call app.Log RedactingLogger.RegisterSecret(token) before any log call that may include tool stderr; XCUT-07 |
| T-04-01-03 | Tampering | Staging file path traversal (WorkDir + "inputs/passive."+toolName) | mitigate | toolName is a hard-coded string literal in each Task struct (e.g. "subfinder") — not derived from user input; no path traversal possible |
| T-04-01-04 | Tampering | MergeStage reads all inputs/passive.*.txt (glob) | mitigate | Glob is scoped to workspace WorkDir which is validated at Target creation; staged files are written by Tasks within the same process (trusted origin) |
| T-04-01-SC | Tampering | npm/pip installs in tools.lock | mitigate | plan-00 added the entries; executor must verify module paths against STACK.md; Phase 11 adds SHA-256 pins |
</threat_model>
