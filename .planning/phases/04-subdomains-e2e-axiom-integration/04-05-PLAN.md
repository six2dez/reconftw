## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| subzy/dnstake output → takeover staging files | Takeover findings written to per-tool staging files; command layer merges and calls single Append (B2 fix) |
| ipinfo.io API response → HostRecord | Third-party API response parsed for geo data; malformed response must not panic; PDCP key redacted |
| Zone transfer response → staging file | DNS AXFR response is untrusted data; hostnames validated by MergeStage scope filter |
| cfg.Subdomains.ZoneTransfer.Enabled | Explicit opt-in gate; breach of gate = active scanning of nameservers without user consent |
| cfg.APIKeys.PDCP → HTTP headers | Secret key must be registered before any log line that could include it |
