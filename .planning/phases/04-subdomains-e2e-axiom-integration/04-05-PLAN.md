<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| subzy/dnstake output → findings.jsonl | Takeover findings written to disk; output from external tool treated as untrusted |
| ipinfo.io API response → HostRecord | Third-party API response parsed for geo data; malformed response must not panic |
| Zone transfer response → staging file | DNS AXFR response is untrusted data; hostnames validated by MergeStage scope filter |
| cfg.Subdomains.ZoneTransfer.Enabled | Explicit opt-in gate; breach of gate = active scanning of nameservers without user consent |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-05-01 | Injection | s3scanner --bucket-file inputs/resolved.merged.txt | mitigate | merged.txt written by MergeStage from scope-filtered Append output; Tool.InputFlag="--bucket-file" declared in tools.lock to prevent heuristic misidentification |
| T-04-05-02 | Information Disclosure | ipinfo.io API key in request headers | accept | ipinfo.io free tier requires no key; paid tier key would be in cfg.APIKeys (Secret-typed, redacted); not in scope for Phase 4 |
| T-04-05-03 | Spoofing | Zone transfer returns forged subdomain records | mitigate | Zone transfer results feed into MergeStage which calls OutputTree.Append with scope filter; forged out-of-scope records are rejected |
| T-04-05-04 | Tampering | Zone transfer AXFR without AllowTransfer opt-in | mitigate | ZoneTransferTask.Run() independently checks cfg.Subdomains.ZoneTransfer.Enabled and returns StatusSkipped if false — defense in depth beyond Enabled() which Scheduler doesn't call |
</threat_model>
