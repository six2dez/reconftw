<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| favirecon/subjs/jsluice stdout → extractor | Tool output (URLs, hashes, subdomains) parsed as untrusted strings |
| Temp file write → jsluice input | subjs output written to raw/subjs.tmp.txt; jsluice reads it — no escaping needed since jsluice receives a file path arg |
| analytics output → subdomain candidates | analyticsrelationships output may contain third-party domains; Extract filters to target domain |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03-01 | Injection | jsluice -i tempFile path | mitigate | tempFile is constructed via filepath.Join(WorkDir, "raw", "subjs.tmp.txt") — WorkDir validated at Target creation; no user-controlled path component |
| T-04-03-02 | Information Disclosure | JS URLs extracted may include secrets in URL paths | mitigate | extract/js returns only Subdomain+URL fields from jsluice; secret fields in jsluice output are NOT included in the SubdomainRecord staging write; Phase 5 handles secret extraction separately |
| T-04-03-03 | Tampering | Temp file race (two concurrent SubScrapingTask runs) | accept | SubScrapingTask runs once per target per stage; Scheduler ensures single instance per task name per RunStage invocation |
</threat_model>
